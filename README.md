# سياق (Siyaq)

أداة لتعلّم كلمات **أكسفورد 5000** للمتحدثين بالعربية، بالترتيب حسب المستويات
(A1 ← A2 ← B1 ← B2 ← C1): بطاقات كلمات يومية، مراجعة متباعدة، وقريبًا قصة يومية واختبار شامل.

## التشغيل

```bash
npm install
npm run dev        # خادم التطوير
npm test           # اختبارات Vitest (المراجعة المتباعدة، المحمّل، الخطة…)
npm run build      # فحص الأنواع + بناء PWA في dist/
```

## ملف الكلمات

- يقرأ التطبيق `data/oxford5000.csv` إن وُجد، وإلا يستخدم ملف التجربة `data/sample.csv`
  (40 كلمة من A1 و20 من A2 مع محتوى ثابت).
- الأعمدة: `word,level,pos` — مثال: `family,A1,noun`. يمكن إضافة عمود رابع اختياري `topic`
  (مثل `people`, `food`, `travel`… انظر `src/lib/topics.ts`).
- القائمة الكاملة ملك لمطبعة جامعة أكسفورد: **لا تُكشط ولا تُرفع إلى git** (الملف مُدرج في `.gitignore`).
  ضعها بنفسك في `data/oxford5000.csv` ثم أعد تشغيل `npm run dev`.
- لتحويل ملفَّي PDF الرسميين (Oxford 3000 by CEFR level و Oxford 5000) إلى هذا الملف:
  `python3 scripts/oxford_pdf_to_csv.py "The_Oxford_3000_by_CEFR_level.pdf" "American_Oxford_5000.pdf"`
  (يحتاج `pdftotext`). الكلمة التي لها معانٍ أو أنواع في مستويات مختلفة تظهر في أكثر من سطر.
- الترتيب: المستوى أولًا (صارم)، ثم مجموعات المواضيع (عائلة، طعام، سفر…)، لا ترتيب أبجدي.

## البنية

| المسار | الدور |
| --- | --- |
| `src/lib/srs.ts` | منطق المراجعة المتباعدة (1 ← 3 ← 7 ← 14 ← 30 يومًا) — وحدة نقية مع اختبارات |
| `src/lib/quiz.ts`, `selection.ts` | مولّد الاختبارات (إملاء، عربي ← إنجليزي، أكمل الجملة، اختيار من متعدد) واختيار كلمات الاختبار الأسبوعي واختبار المستوى |
| `src/lib/streak.ts` | سلسلة الأيام المتتالية |
| `src/lib/plan.ts` | الخطة اليومية، احتساب الكلمات المعروفة، التقديرات |
| `src/lib/csv.ts`, `words.ts`, `topics.ts` | قراءة الملف وترتيب الكلمات ومجموعات المواضيع |
| `src/lib/typing.ts`, `highlight.ts`, `speech.ts` | مقارنة الكتابة، تظليل الكلمة في الجملة، النطق |
| `src/db/` | IndexedDB عبر Dexie: الكلمات، التقدّم، الإعدادات، خطة اليوم |
| `src/screens/`, `src/components/` | الواجهة (عربية RTL، والإنجليزية داخلها `dir="ltr"`) |
| `src/data/sampleContent.ts` | محتوى ثابت لكلمات ملف التجربة (سيُولّد بالذكاء الاصطناعي في المرحلة 4) |

`src/lib` لا يعتمد على React ولا على قاعدة البيانات، ليُعاد استخدامه لاحقًا في إضافة المتصفح.

## المفاتيح

مفتاح `ANTHROPIC_API_KEY` سيُستخدم فقط في دالة الخادم `/api/story` (المرحلة 3) — انظر `.env.example`.
لا يوضع أي مفتاح في كود الواجهة، وملفات `.env` مُستثناة من git.

## مراحل العمل

1. ✅ **الأساس**: المشروع، المحمّل، قاعدة البيانات، «من وين تحب تبدأ؟»، عدد الكلمات اليومي،
   بطاقة الكلمة بمراحلها الخمس، المراجعة المتباعدة مع اختباراتها.
2. ✅ **الاختبار الشامل** (4 أنواع أسئلة)، **دفتر الأخطاء** (يظهر أولًا في مراجعات الغد)، **شاشة التقدّم**
   (العدّاد، المستويات، سلّم المراجعة، السلسلة، النشاط)، الاختبار الأسبوعي، واختبار نهاية المستوى الاختياري.
3. قصة اليوم: التوليد بالذكاء الاصطناعي، الاستماع، التظليل.
4. توليد محتوى الكلمات مع التخزين المؤقت، اختبار تحديد المستوى.
5. إضافة المتصفح (Chrome MV3).

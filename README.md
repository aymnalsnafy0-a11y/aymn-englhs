# سياق (Siyaq)

أداة لتعلّم كلمات **أكسفورد 5000** للمتحدثين بالعربية، بالترتيب حسب المستويات
(A1 ← A2 ← B1 ← B2 ← C1): بطاقات كلمات يومية، مراجعة متباعدة، وقريبًا قصة يومية واختبار شامل.

## التشغيل

```bash
npm install
npm run dev        # خادم التطوير
npm test           # اختبارات Vitest (المراجعة المتباعدة، المحمّل، الخطة…)
npm run build      # فحص الأنواع + بناء PWA في dist/
```

## الموقع على GitHub Pages

النسخة الثابتة منشورة على https://aymnalsnafy0-a11y.github.io/aymn-englhs/ وتتحدّث تلقائيًا مع كل دفع
(`.github/workflows/pages.yml`). لتجهيزها للمذاكرة (مرة واحدة في كل جهاز):

1. **الإعدادات ← قائمة الكلمات ← حمّل ملف الكلمات**: اختر `oxford5000.csv` (ينتجه `scripts/oxford_pdf_to_csv.py`).
   الملف يُحفظ في المتصفح فقط ولا يُنشر.
2. **الإعدادات ← مفتاح Gemini**: الصق مفتاحًا مجانيًا من https://aistudio.google.com/apikey. يُحفظ في هذا الجهاز فقط،
   والتطبيق يتصل بـ Gemini مباشرة من المتصفح بنفس منطق الخادم (`src/data/ai.ts`).

على Vercel يبقى المفتاح في الخادم (`GEMINI_API_KEY`) ولا يحتاج المستخدم إدخاله.

### الحساب والمزامنة

نفس مشروع Firebase وحساب موقع «دروس الصينية» (إيميل وكلمة مرور). بيانات الإنجليزي في
`learners/{uid}/state/english`, `english-progress`, `english-stories`, `english-wordlist` — منفصلة عن مستند
الصيني `main`. الدمج بين الأجهزة في `src/lib/sync.ts` (الأحدث لكل عنصر، والاتحاد للأيام والاختبارات)،
والاتصال في `src/data/cloud.ts`. يجب أن تسمح قواعد Firestore بـ `learners/{uid}/state/{doc}` لصاحب الحساب.
مفتاح Gemini لا يُزامَن (يبقى في كل جهاز).

## ملف الكلمات

- يقرأ التطبيق `data/oxford5000.csv` إن وُجد، وإلا يستخدم ملف التجربة `data/sample.csv`
  (40 كلمة من A1 و20 من A2 مع محتوى ثابت).
- الأعمدة: `word,level,pos` — مثال: `family,A1,noun`. يمكن إضافة عمود رابع اختياري `topic`
  (مثل `people`, `food`, `travel`… انظر `src/lib/topics.ts`).
- القائمة الكاملة ملك لمطبعة جامعة أكسفورد: **لا تُكشط ولا تُرفع إلى git** (الملف مُدرج في `.gitignore`).
  ضعها بنفسك في `data/oxford5000.csv` ثم أعد تشغيل `npm run dev`.
- لتحويل ملفَّي PDF الرسميين (Oxford 3000 by CEFR level و Oxford 5000) إلى هذا الملف:
  `python3 scripts/oxford_pdf_to_csv.py "The_Oxford_3000_by_CEFR_level.pdf" "American_Oxford_5000.pdf"`
  (يحتاج `pdftotext`). الكلمة التي لها معانٍ أو أنواع في مستويات مختلفة تظهر في أكثر من سطر.
- الترتيب: المستوى أولًا (صارم)، ثم مجموعات المواضيع (عائلة، طعام، سفر…)، لا ترتيب أبجدي.

## البنية

| المسار | الدور |
| --- | --- |
| `src/lib/srs.ts` | منطق المراجعة المتباعدة (1 ← 3 ← 7 ← 14 ← 30 يومًا) — وحدة نقية مع اختبارات |
| `src/lib/quiz.ts`, `selection.ts` | مولّد الاختبارات (إملاء، عربي ← إنجليزي، أكمل الجملة، اختيار من متعدد) واختيار كلمات الاختبار الأسبوعي واختبار المستوى |
| `src/lib/streak.ts` | سلسلة الأيام المتتالية |
| `src/lib/storyText.ts`, `storyPlayer.ts` | تقسيم الجمل المختلطة، وتشغيل القصة مع تتبّع الكلمة المنطوقة |
| `server/gemini.ts` | استدعاء Gemini المشترك: مخرجات JSON بمخطط، نماذج بديلة عند الازدحام، مهلة إجمالية |
| `server/story.ts`, `server/content.ts`, `api/*.ts` | القصة، محتوى الكلمات، تصنيف المواضيع — ودوال Vercel لكل منها |
| `src/data/content.ts` | مخزن محتوى الكلمات (المولَّد + الثابت) وتوليد الناقص عند الحاجة |
| `src/lib/placement.ts` | اختبار تحديد المستوى وحساب الدرجة المصحّحة |
| `src/lib/browse.ts`, `extension/` | منطق إضافة المتصفح المشترك، والإضافة نفسها (محتوى، جسر، خلفية، نافذة) |
| `src/lib/plan.ts` | الخطة اليومية، احتساب الكلمات المعروفة، التقديرات |
| `src/lib/csv.ts`, `words.ts`, `topics.ts` | قراءة الملف وترتيب الكلمات ومجموعات المواضيع |
| `src/lib/typing.ts`, `highlight.ts`, `speech.ts` | مقارنة الكتابة، تظليل الكلمة في الجملة، النطق |
| `src/db/` | IndexedDB عبر Dexie: الكلمات، التقدّم، الإعدادات، خطة اليوم |
| `src/screens/`, `src/components/` | الواجهة (عربية RTL، والإنجليزية داخلها `dir="ltr"`) |
| `src/data/sampleContent.ts` | محتوى ثابت لكلمات ملف التجربة (سيُولّد بالذكاء الاصطناعي في المرحلة 4) |

`src/lib` لا يعتمد على React ولا على قاعدة البيانات، ليُعاد استخدامه لاحقًا في إضافة المتصفح.

## قصة اليوم والمفتاح

- القصص تُولَّد عبر **Gemini** (مستوى مجاني) في دالة الخادم `api/story.ts` ← `server/story.ts`.
  المفتاح لا يصل للواجهة أبدًا.
- محليًا: ضع `GEMINI_API_KEY=...` في ملف `.env` (انظر `.env.example`) ثم `npm run dev` — خادم التطوير يخدم `/api/story`.
- على Vercel: استورد المستودع (يتعرّف على Vite تلقائيًا)، ثم أضف `GEMINI_API_KEY` في
  Project Settings ← Environment Variables وأعد النشر.
- عند ازدحام النموذج يجرّب الخادم النماذج بالترتيب (`GEMINI_MODELS`)، ويعيد المحاولة مرة إذا نسي النموذج كلمات اليوم.
- ملفات `.env` مُستثناة من git.

## مراحل العمل

1. ✅ **الأساس**: المشروع، المحمّل، قاعدة البيانات، «من وين تحب تبدأ؟»، عدد الكلمات اليومي،
   بطاقة الكلمة بمراحلها الخمس، المراجعة المتباعدة مع اختباراتها.
2. ✅ **الاختبار الشامل** (4 أنواع أسئلة)، **دفتر الأخطاء** (يظهر أولًا في مراجعات الغد)، **شاشة التقدّم**
   (العدّاد، المستويات، سلّم المراجعة، السلسلة، النشاط)، الاختبار الأسبوعي، واختبار نهاية المستوى الاختياري.
3. ✅ **قصة اليوم**: قصة للمبتدئ (عربي وكلمات اليوم بالإنجليزية) أو للمتقدم (إنجليزية كاملة)، حلقات متسلسلة
   أو مستقلة، استماع مع تظليل الكلمة المنطوقة وثلاث سرعات وإعادة الجملة ووضع «استماع فقط»، ترجمة الجملة بالضغط،
   بطاقة الكلمة بالضغط، 3 أسئلة فهم، ومكتبة القصص.
4. ✅ **محتوى الكلمات بالذكاء الاصطناعي**: المعنى، المقاطع، جملتان، طريقة تذكّر، عائلة الكلمة — يُولَّد عند الحاجة
   (دفعات من 10) ويُخزَّن في المتصفح ولا يُعاد توليده. **تصنيف المواضيع** في الخلفية (دفعات من 200) لترتيب الكلمات
   داخل المستوى. **اختبار تحديد المستوى**: «أعرفها / لا أعرفها» مع كلمات مختلقة لخصم التخمين.
5. ✅ **إضافة المتصفح** (Chrome MV3): تظليل كلماتك في المواقع الإنجليزية مع المعنى عند التمرير، استبدال معاني
   كلماتك بالإنجليزية في المواقع العربية، نسبة فهم الصفحة، وحفظ كلمات جديدة لخطتك (قائمة الزر الأيمن أو النافذة).

## إضافة المتصفح

```bash
npm run build:extension    # يبني الإضافة في extension/dist
```

1. افتح `chrome://extensions` وفعّل «وضع المطوّر».
2. اضغط «تحميل إضافة غير مضغوطة» واختر مجلد `extension/dist`.
3. افتح تطبيق سياق مرة (على `localhost` أو رابط `*.vercel.app`) لتتم مزامنة كلماتك مع الإضافة.

- الإضافة لا تتصل بأي خادم؛ تتبادل البيانات مع التطبيق عبر سكربت صغير يعمل في صفحة التطبيق فقط
  (`extension/src/bridge.ts`). لاستخدام نطاق خاص غير `vercel.app` أضفه في `extension/public/manifest.json`.
- الكلمات المحفوظة من المواقع تدخل خطتك أولًا (حتى لو كانت من مستوى أقل)، والكلمات خارج قائمة أكسفورد تُرفض مع تنبيه.
- المنطق المشترك مع التطبيق في `src/lib/browse.ts` (المطابقة مع التصريفات، السوابق واللواحق العربية، نسبة الفهم).
